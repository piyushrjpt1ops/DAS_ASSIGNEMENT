# Recursion Practice Assignment (Java)

This repository contains separate Java solutions for all 26 questions in the Recursion Practice Assignment.

## Files
- Q1–Q6: Basic recursion
- Q7–Q8: Strings
- Q9–Q13: Number recursion
- Q14: Fibonacci series
- Q15–Q18: GCD, LCM, and number conversion
- Q19–Q21: Character and string operations
- Q22–Q26: Arrays and searching

## How to run
Compile and run one file at a time. Example:

```bash
javac Q1_PrintNumbers1ToN.java
java Q1_PrintNumbers1ToN
```

Each Java file contains its own `main` method and reads input in the format described in the assignment.

Note: The solutions use recursion as requested. Inputs should follow the constraints in the assignment; array questions require a positive array size.
